# Limitations

- Requires network access, supported microphone permissions and OpenAI model access. API quotas and provider outages still apply.
- Chrome on Android is the primary field browser. Keep it foregrounded; screen-lock/background recording and Bluetooth routing need device-specific testing.
- No background wake word. Tap to connect; then “Hey Lindsay” is simply a conversational address.
- Reminder entries do not send notifications. Saved issues are not automatically resolved or assigned.
- Speech recognition and model interpretation can be wrong; ambiguous writes should be clarified. Only successful tool results confirm a save.
- Exa is optional public web retrieval, not a guaranteed real-time traffic, inventory, maps or business-hours feed. Search timestamps are not source-update timestamps. A source may be outdated, incomplete or hostile.
- Public web content is untrusted and must not override instructions or authorize actions. Privacy filters are defensive checks, not a proof that arbitrary text is non-sensitive.
- Authorized attendee fields depend on the AI Tinkerers API. There is no verified person-to-team/solo mapping in the implemented profile endpoint and no justified ranking of “strongest engineers.”
- The public repository contains fictional data, not the operational runbook. The live Site is private; its URL is not an access grant.
- This is a hackathon MVP, not a full event-management system or an independently security-certified product.
